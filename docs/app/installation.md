# Installation

## Windows

- [Download](https://github.com/tom-mohr/particle-life-app/releases/latest/download/particle-life-app.zip)
- Unzip the file into a new folder.
- Run the .exe inside this folder.

## Linux

- Install a JDK (version 17–25).
    - If not sure, download [Adoptium](https://adoptium.net), it should be distro-agnostic.
- Clone the repository:
  `git clone https://github.com/tom-mohr/particle-life-app.git`
- Enter the folder and run the app:
  `cd particle-life-app`
  `./gradlew run`
